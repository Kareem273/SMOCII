# SMOCII - منصة الإقلاع عن التدخين الذكية الشاملة
### Smart Biomarker & AI-Assisted Smoking Cessation Ecosystem

نظام رقمي وطبي متكامل مصمم لمساعدة الأفراد على التعافي التام والمستدام من إدمان النيكوتين، معتمداً على بروتوكولات عيادات الإقلاع عن التدخين التابعة لـ **وزارة الصحة والسكان المصرية**، ومدعوماً بجهاز استشعار حيوي بالبلوتوث (BLE Companion Device) ومرشد ذكي تفاعلي فائق التعاطف (Empathetic AI Coach).

---

## 🌟 المكونات الأساسية للنظام (System Architecture)

### 1. تطبيق الهاتف الذكي (`smokii_app`) - Flutter
* **خطة علاجية معتمدة من وزارة الصحة (MOHP Protocol):**
  * تصنيف فاجرستروم الإكلينيكي (Fagerström Test - FTND) لتحديد درجة الاعتماد الفسيولوجي بدقة.
  * 4 مراحل إكلينيكية متدرجة (التحضير الصباحي، إدارة الانسحاب بدرع الـ 4D's، التخفيض المتدرج للجرعات، والوقاية من الانتكاسة).
  * توليد آلي بالكامل بدون تشتيت المستخدم بخيارات معقدة.
  * ربط مباشر بالخط الساخن الوطني للإقلاع عن التدخين لعلاج الإدمان: **16805**.
* **المرشد الذكي التفاعلي (Empathetic AI Coach):**
  * دعم إنساني نفسي تفاعلي (CBT) يجيب على كافة الأسئلة (المدة الزمنية للتعافي، أعراض الانسحاب، تنظيم النوم والشهية، كسر عادة القهوة).
  * تكامل مباشر مع محرك **Google Gemini 1.5 Flash** للمحادثات المفتوحة.
* **الربط مع جهاز الاستشعار الحيوي (BLE Companion Device):**
  * فحص هواء الزفير وقياس مستويات أول أكسيد الكربون (PPM) عبر تقنية البلوتوث منخفض الطاقة (BLE).
  * تفعيل بروتوكول التدخل السريع التلقائي عند رصد قراءات نيكوتين مرتفعة.
* **درع الطوارئ لمكافحة الرغبة الملحة (Craving SOS Shield):**
  * مؤقت تأخير 5 دقائق (Delay Timer).
  * تمرين التنفس البطني الاسترخائي (4-7-8 Breathing Pacer).

### 2. الخادم الخلفي وقاعدة البيانات (`smokii_backend`) - Node.js Express
* خادم RESTful API لتسجيل قراءات المستشعر الحيوي، ومتابعة سلسلة الأيام النظيفة (Streaks).
* محرك ذكاء اصطناعي تفاعلي يعالج المحادثات ويدمج مقاييس المستشعر في الردود.
* حفظ دائم للبيانات في `database.json`.

## 🚀 كيفية التشغيل (How to Run)

### تشغيل التطبيق (Flutter App):
```bash
cd smokii_app
flutter pub get

# للتشغيل على الويب (Chrome):
flutter run -d chrome

# للتشغيل كتطبيق ويندوز محلي:
flutter run -d windows
```

### تشغيل الباك إند (Node.js Server):
```bash
cd smokii_backend
npm install
npm start
# الخادم سيعمل على المنفذ 5000: http://localhost:5000
```
